# Chamego Site

Aplicação React (versão estável mais recente) com base moderna e simples para um sistema completo e responsivo.

## Stack

- React 19 + Vite
- React Router DOM
- Material UI (layout responsivo)
- React Query + Axios
- Zustand
- React Hook Form + Zod

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
npm run preview
```
